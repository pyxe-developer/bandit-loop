# Script And Stage Dispatch Contracts

Scaffold placeholder for JSON-in/JSON-out script contracts and stage dispatch
payloads.

Reserved script entrypoints:

- `scripts/route-card`
- `scripts/evidence-ledger`
- `scripts/verify-stage`
- `scripts/review-package`
`orchestrate-assisted` owns stage dispatch over the core scripts. Claude-native
agents and lifecycle hooks are configured by the plugin manifest and are not
installed through additional Codex-specific scripts.
